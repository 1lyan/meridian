# Postmortem

Copy this file for an incident. Write it after the system is stable. Name what the system did. Leave blame out.

## Summary

One or two sentences. What broke, who was affected, and how long.

## Impact

- Tenants affected:
- Orders stuck, and in which status:
- Data lost, if any:
- Start and end (UTC):

## Timeline

| Time (UTC) | Event                  |
| ---------- | ---------------------- |
|            | First symptom          |
|            | Change that stopped it |

## What happened

The trigger, what the saga or the database did, and why the existing checks did not catch it.

## What worked

Detection, the runbook that was used, and the restore or the destroy that limited the damage.

## What did not

Missing alerts, a drill that had not been run, or a step that was wrong.
